# 📖 TypeScript Learning Guide - Daily Plan

This guide provides a detailed day-by-day plan for your 1-month TypeScript learning journey.

## 🎯 Learning Principles

1. **Learn by Doing**: Read the code, run it, then modify it
2. **Practice Daily**: Even 30 minutes of consistent practice is better than sporadic study
3. **Build Projects**: Apply concepts immediately in practical scenarios
4. **Ask Questions**: Research anything you don't understand

---

## Week 1: TypeScript Basics (Days 1-7)

### Day 1: Introduction & Basic Types
- **Learn**: `src/week1/01-basic-types.ts`
- **Topics**: 
  - String, Number, Boolean types
  - Arrays and Tuples
  - Enums
  - Any, Unknown, Void, Null, Undefined
- **Practice**: Try creating variables with different types
- **Time**: 1-2 hours

### Day 2: More Basic Types
- **Review**: `src/week1/01-basic-types.ts` again
- **Practice**: 
  - Create your own examples with each type
  - Try to break the type system intentionally to see error messages
- **Challenge**: Create a type for your favorite things (movies, books, etc.)
- **Time**: 1-2 hours

### Day 3: Functions (Part 1)
- **Learn**: `src/week1/02-functions.ts` (first half)
- **Topics**: 
  - Function parameters and return types
  - Optional parameters
  - Default parameters
  - Rest parameters
- **Practice**: Write 5 different functions with proper typing
- **Time**: 1-2 hours

### Day 4: Functions (Part 2)
- **Learn**: `src/week1/02-functions.ts` (second half)
- **Topics**: 
  - Arrow functions
  - Function types
  - Function overloading
  - Generic functions
- **Practice**: Refactor your Day 3 functions using different styles
- **Time**: 1-2 hours

### Day 5: Interfaces
- **Learn**: `src/week1/03-interfaces-types.ts` (first half)
- **Topics**: 
  - Basic interfaces
  - Optional properties
  - Readonly properties
  - Extending interfaces
- **Practice**: Model your daily routine using interfaces
- **Time**: 1-2 hours

### Day 6: Type Aliases & Advanced Types
- **Learn**: `src/week1/03-interfaces-types.ts` (second half)
- **Topics**: 
  - Type aliases
  - Union types
  - Intersection types
  - Index signatures
- **Practice**: Start Week 1 exercises in `exercises/week1/exercises.ts`
- **Time**: 2-3 hours

### Day 7: Week 1 Review & Practice
- **Review**: All Week 1 materials
- **Complete**: All exercises in `exercises/week1/exercises.ts`
- **Mini Project**: Create a simple "Person" management system with CRUD operations
- **Time**: 2-4 hours

## 💡 Tips for Success

1. **Don't rush**: Understanding is more important than speed
2. **Type everything**: Avoid `any` unless absolutely necessary
3. **Read errors carefully**: TypeScript errors are very informative
4. **Use IDE features**: Take advantage of autocomplete and type checking
5. **Experiment**: Try breaking things to understand how they work
6. **Ask for help**: Join TypeScript communities when stuck
7. **Review regularly**: Revisit previous weeks' materials
8. **Build real projects**: Theory is good, but practice is better

---

**Remember**: Learning TypeScript is a journey, not a destination. Enjoy the process! 🚀
