# 🚀 TypeScript Learning Challenge - 1 Month

Welcome to the **1-Month TypeScript Learning Challenge**! This repository contains a comprehensive, structured learning path designed to take you from TypeScript beginner to proficient developer in just one month.

## 📚 Course Overview

This challenge is organized into 4 weeks, with each week focusing on different aspects of TypeScript:

### Week 1: TypeScript Basics
Learn the fundamentals of TypeScript including:
- ✅ Basic types (string, number, boolean, arrays, tuples, enums)
- ✅ Functions and their type annotations
- ✅ Interfaces and type aliases
- ✅ Union and intersection types

### Week 2: Advanced Types
Master advanced TypeScript features:
- ✅ Generics and generic constraints
- ✅ Utility types (Partial, Required, Pick, Omit, Record, etc.)
- ✅ Type guards and type narrowing
- ✅ Discriminated unions

### Week 3: Object-Oriented Programming
Dive into OOP concepts in TypeScript:
- ✅ Classes and inheritance
- ✅ Access modifiers (public, private, protected)
- ✅ Abstract classes
- ✅ Design patterns (Singleton, Factory, Observer, Strategy, Decorator)

### Week 4: Practical Projects
Build real-world applications:
- ✅ Todo List Application
- ✅ User Management System
- ✅ Apply all learned concepts in practical scenarios

## 🛠️ Setup Instructions

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone this repository:
```bash
git clone https://github.com/mehar99197/Typescript.git
cd Typescript
```

2. Install dependencies:
```bash
npm install
```

## 🎯 How to Use This Repository

### Running Examples

Each week has example files in the `src/` directory. To run any example:

```bash
# Run a specific lesson
npm run dev src/week1/01-basic-types.ts

# Or use the interactive menu
npm start
```

### Working on Exercises

Practice exercises are located in the `exercises/` directory. Each week has its own set of exercises:

```bash
# Open the exercise file for the week you're on
# For example, Week 1 exercises:
code exercises/week1/exercises.ts
```

Complete the TODO sections in each exercise file and run them to test your solutions:

```bash
npm run dev exercises/week1/exercises.ts
```

### Building the Project

Compile all TypeScript files to JavaScript:

```bash
npm run build
```

Compiled files will be in the `dist/` directory.

### Watch Mode

For continuous compilation during development:

```bash
npm run watch
```

## 🎓 Learning Tips

1. **Practice Daily**: Consistency is key. Try to code every day, even if it's just for 30 minutes.

2. **Type Everything**: Resist the temptation to use `any`. Proper typing is the whole point of TypeScript!

3. **Read the Examples**: Don't just run the code - read it, understand it, and try modifying it.

4. **Do the Exercises**: The exercises are designed to reinforce what you've learned. Don't skip them!

5. **Build Projects**: Apply your knowledge by building small projects. The best way to learn is by doing.

6. **Use TypeScript Playground**: Try out code snippets at [TypeScript Playground](https://www.typescriptlang.org/play)

7. **Read Documentation**: The [Official TypeScript Documentation](https://www.typescriptlang.org/docs/) is excellent.
